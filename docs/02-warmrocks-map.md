## Scene Reference

### 1. Rikko Camp / Rikko's Porch

Traversal role:

- Central entry from Driftwood Shore.
- Main hub return point after each major location.
- Final ending return.

POI spec:

- Rikko NPC.
- Main quest dialogue: Golden Skull objective.
- Visible routes toward shop, ship path, high route, and sanctuary approach.
- Ending interaction point after Golden Skull is obtained.
- Optional note bottle for hub orientation.

Challenges and hazards:

- No combat.
- No lethal hazards.

Items and rewards:

- Quest starts.
- Possible first hint toward The Wrong Ship.

### 2. Campfire and Shop / The Warm Deal

Traversal role:

- Main service scene.
- Leads south toward The Wrong Ship.

POI spec:

- Campfire checkpoint.
- Main teleporter or teleporter activation point.
- Rikko shop shelf or merchant interface.
- Supply display: healing bottles, throwable sabres, rum, optional perks.
- Clear southern exit toward the ship.

Challenges and hazards:

- No combat.
- Safe preparation area.

Items and rewards:

- Checkpoint.
- Shop access.
- Healing and combat supplies.

### 3. Training and Upgrade Yard / Hardhead Yard

Traversal role:

- Optional hub service branch.
- Useful after sabre and after collecting diamonds.

POI spec:

- Training dummy.
- Upgrade statue.
- Diamond cost display for Vitality I and Strength I.
- Small flat practice space.

Challenges and hazards:

- No danger.
- Sabre timing and hit feedback.

Items and rewards:

- Vitality I upgrade access.
- Strength I upgrade access.
- Optional damage feedback from dummy.

### 4. Upper Anchor Path / Cloud Steps

Traversal role:

- Main northern route after the ship reward.
- Leads to Cloud Mountain.

POI spec:

- High ledges visible before the player can reach them.
- Anchor path or vertical traversal route.
- Route gate toward Cloud Mountain.
- Optional coin trail to guide first use.

Challenges and hazards:

- Traversal-gated ascent.
- No heavy enemy pressure in the hub.

Items and rewards:

- Route to Cloud Mountain.

### 5. Candle Gate / Little-Star Mouth

Traversal role:

- Optional or shortcut branch after fireflies.
- Can connect back into hub circulation.

POI spec:

- Candle door or lightcatcher.
- Small reward pocket or shortcut door.
- Clear visual language for small lights opening old stone.

Challenges and hazards:

- Firefly/light activation.
- No mandatory combat.

Items and rewards:

- Shortcut or small chest.
- Coins, rum, or minor supply.

### 6. Sanctuary Approach / Skullwatch Stones

Traversal role:

- Eastern final gate.
- Visible early, opened after Cloud Mountain mechanisms.
- Contains optional dangerous side path.

POI spec:

- Large sealed sanctuary door.
- Stone markers or skullwatch props.
- Optional side path near the sealed door.
- Permanent open state after ruins progress.

Challenges and hazards:

- Main door locked until sanctuary is opened.
- Optional side path can include spikes, one sea star, and possibly one totem.

Items and rewards:

- Sanctuary access later.
- Optional diamonds, rum, and coins from the side path.

## Layout Notes

- Warmrocks should be easy to read because it is revisited often.
- The ship exit goes south from the service scene.
- The Cloud Mountain route goes north and should feel like an ascent.
- Skullkeeper Hollow sits east of the hub and should feel important even while
  locked.
