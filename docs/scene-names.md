# Scene Name Suggestions

This document suggests player-facing scene names for the lite walkthrough in
`docs/walkthrough-plan-lite.md` and `docs/scene-traversal-lite.md`.

These names are meant to work as map labels. They should feel like names used
by the island's native inhabitants: mostly simple, non-scholarly, practical,
superstitious, and sometimes funny. The names should describe what locals can
see, hear, fear, eat, avoid, or tell stories about.

They should not sound like names invented by a game designer or a player who
understands the mechanics.

Russian names are not strict literal translations. They are adapted to keep the
same simple island-local style and should be treated as player-facing map names
for a Russian localization.

## Naming Direction

Recommended style:

- Use short names, usually 2-4 words.
- Prefer simple natural words: cloud, stone, tooth, belly, hill, smoke, mud,
  hush, sky, salt, eye, mouth, nest, sleep, thunder, gold.
- Name places after visible shape, danger, local myth, smell, sound, or bad
  memories.
- Use humor through blunt local logic, not modern jokes.
- Keep map labels easy to remember and pronounce.
- Avoid similar names inside the same location.

Avoid names that directly mention player abilities or game systems:

- Do not use hook, anchor, grapple, swing, climb, upgrade, checkpoint, boss,
  teleporter, shortcut, gate key, tutorial, projectile, mechanism, or arena.
- Avoid firefly in most place names. Locals may know glowing bugs, but map names
  should usually refer to glow, lamps, stars, or little lights instead.
- Avoid names that reveal exactly how the player solves the scene.
- Avoid names that reveal a specific enemy, item, reward, or boss before the
  player has encountered it.

Good map names should answer at least one question:

- What does this place look like?
- What danger do locals remember here?
- What old story would be told about this place?
- Would a nervous islander avoid it, respect it, or laugh at it?

## Implementation Note

For Unity scene asset names, the `Scene Id Suggestion` column avoids spaces,
apostrophes, and punctuation. For player-facing map UI, use the `Map Name`
column in English builds and the `Russian Map Name` column in Russian builds.
This keeps code and scene references simple while still allowing flavorful names
on the map.
